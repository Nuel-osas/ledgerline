The problem

Alone, every operator looks unbankable.

Someone runs a hotspot on one network, a storage node on another, a sensor on a third. Each network settles its own rewards on its own chain.

  • The wireless network sees the hotspot. The storage network sees the node. Neither sees the other.
  • To every individual network the operator is a stranger with nothing to pledge.
  • In aggregate they are obviously good for it, and no network can see the aggregate.

How it works

Only a fact crosses. No token ever does.

Ethereum Sepolia

A network settles earnings and emits PaymentMade(operator, amount, period).

It never touches Creditcoin, signs nothing there, and bridges nothing.

Creditcoin CC3

Anyone submits an Attestcoin proof to IncomeRegistry.execute().

The 0x0FD2 precompile verifies it in that same transaction, and the settlement folds into one profile.

limit = run-rate per period  x  (history + diversification)
Proof submission is permissionless03
The insight

Diversification is priced, because it is real.

500 a period from one network is a worse credit than 500 across three. The first has a single point of failure: that network degrades and 100% of the income stops.

1 network   ->  +0
2 networks  ->  +15%
3 or more   ->  +30%

No individual network can price this, because none of them can see the others. Creditcoin can, because every stream is proven into the same registry.

Risk

A node that stops earning has stopped working.

There is no collateral to seize, so the risk model is cadence. For physical infrastructure that is a direct default signal rather than a proxy: revenue stops when the hardware stops.

During development the registry accepted a fully proven six-period history and still returned a limit of zero, because that revenue was six months stale. The freeze fired before it was tested deliberately.

isCurrent() is a liveness check on a device06
Security

Two bugs we shipped, found, and fixed.

  • Open settlement. pay() was permissionless, so a wallet could self-transfer in a loop, netting to zero, and manufacture an earnings record for the price of gas. Now restricted to the network's paymaster. Found by running the attack, not by reading the code.
  • The credit model penalised diversifying. Dividing by settlement count instead of distinct periods meant adding a smaller second stream lowered the limit. Only surfaced once the networks paid different amounts.

The base contract is hardened against two further flaws found in the tutorial's USCBase and filed upstream as gluwa/USC-Builder-Examples#37.
